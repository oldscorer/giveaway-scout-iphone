Using it on iPhone

Install to Home Screen

  1. Open this app’s published HTTPS website in Safari.
  2. Tap the Share icon (square with an up arrow).
  3. Choose Add to Home Screen, then tap Add.
  4. Launch Giveaway Scout from the new Home Screen icon.

The app files need to be hosted on an HTTPS website for the Home Screen installation and offline app shell to work. See the included README for a no-computer publishing route.

How the giveaway loop works

  1. Tap Browse Gleam or use a gaming/tech search.
  2. Choose a giveaway and copy its link from Safari.
  3. Return to Scout and paste the link into Add a giveaway.
  4. Open it from Your queue. Complete required actions manually in the relevant app/site.
  5. Return to Scout, tick off completed tasks, and tap Next.

Privacy & limits

Your saved links and checklist are stored in this browser on this device. The app does not ask for passwords, follow accounts, post comments, or submit entries. iOS keeps other apps and websites isolated, so it cannot automatically verify a follow or comment after you switch apps. Use only giveaways you are eligible for and follow each organizer’s official rules.

Creates a backup file of your saved URLs and checklist. Keep it private if it contains personal notes.
